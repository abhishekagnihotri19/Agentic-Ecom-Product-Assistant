# 🛍️ Agentic E-commerce Product Assistant

> Your Intelligent Shopping Companion – Discover prices, compare products, and make smarter buying decisions using Agentic AI.

---

🚀 Project Overview

Agentic E-commerce Product Assistant is an AI-powered system that helps users interactively search, compare, and analyze products across e-commerce platforms.

It leverages **Agentic AI** to autonomously decide which tools and workflows to use based on user queries.

---

🎯 Key Features

- 🔍 Smart Product Search  
- 💰 Price Comparison  
- ⭐ Review Summarization  
- 🎯 Intelligent Recommendations  
- ⚡ Real-time AI Responses  

---

🧠 Tech Stack

- **Agentic AI Framework**: LangChain  
- **LLM**: Groq Chat Model  
- **Embeddings**: Google Embeddings  
- **Architecture**: MCP Server  
- **Deployment**: AWS EKS (Kubernetes)  
- **Backend**: Python (FastAPI)  


---

⚙️ System Architecture

- Multi-agent orchestration using LangChain  
- Tool-based decision-making system  
- Scalable microservices via MCP Server  
- Kubernetes-based deployment for high availability

🚀 How It Works

1. User enters query (e.g., “Best iPhone under ₹50,000”)  
2. Agent interprets intent  
3. Selects appropriate tools (search, compare, summarize)  
4. Retrieves and processes data  
5. Returns intelligent response
